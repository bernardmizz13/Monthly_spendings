# Monthly spendings analyzer

Repository containg a python script which visualises monthly spendings for each year.

To run the scirpt open a python envirnoment in your terminal and run:

```
python analyze.py date
```
Instead of `date`type in the year for which you wish to analyze the monthly spendings, like for example:

```
python analyze.py 2025
```

If you wish to calculate stats for events denoted by _Sports_ run:

```
python analyze.py 2025 y
```
In folder `data` there is are example CSV files of how the monthly spendings and earnings should be saved and prepared for the python script, before running the script rename the CSV file to `monthly_spendings.csv` and `monthly_earnings.csv`.

The events list should or can be one of your own, meaning that there is no need for any pre-defined list of events, however, ensure that the same name of events are used across all months of the year.

It is important that you store the CSV files with your spendings and earnings in folder `data` using the following path structure:

```
-- 📜 analyse.py          # Main analysis script
│-- 📂 data                # Data storage folder
│   ├── 📜 2025_monthly_earnings.csv    # Monthly earnings data
│   ├── 📜 2025_monthly_spendings.csv   # Monthly spendings data
```

Folders `plots` and `stats` are generated by the script.
